# applications: Laboratories and Tools

*Status: planned.* Edge, at the top of the architecture. It may depend on everything, and nothing depends on it.

## 1. Purpose

This directory holds complete programs that people use. There are two kinds:

- **laboratories**, for learning and research;
- **tools**, for practical work.

Each application declares what it depends on.

## 2. Planned Laboratories (`labs/`)

| Lab | Content |
|---|---|
| Orbital sandbox | Two-body and n-body motion, Kepler's laws, perturbations |
| Tide-predicting machine | A digital version of Kelvin's machine. Each tidal constituent is a wheel, and the tide is their sum. |
| Sight-reduction trainer | Finding a position from star sights by spherical trigonometry |
| Rotating tank | Shallow water on a rotating sphere; Kelvin and Rossby waves, in ocean and atmosphere alike |
| Weather-map lab | Geostrophic wind, fronts and cyclones, shown on real analyses |
| Energy-balance lab | The Earth's radiation budget and the greenhouse effect, starting from a single-layer model |
| Milankovitch lab | The Earth's orbital elements, insolation, and the ice ages |
| Projection lab | Map projections and their distortions |
| Foucault pendulum | The rotation of the Earth made visible |

## 3. Planned Tools (`tools/`)

- An ephemeris calculator.
- A tide predictor.
- A planetarium and globe viewer.
